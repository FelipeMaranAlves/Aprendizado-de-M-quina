1. ANÁLISE DE DISTRIBUIÇÃO (HISTOGRAMAS):
Os histogramas gerados dividem a frequência das features por classe (0 = Benigno, 1 = Malicioso).
Observou-se que features estruturais do PDF (ex: contagem de objetos ou streams específicos)
apresentam forte assimetria à direita, concentrando a classe benigna próxima de zero,
enquanto anomalias/malwares deslocam-se para caudas mais longas com valores elevados.

Esses gráficos confirmam visualmente a viabilidade de utilizar algoritmos de detecção
de anomalias (K-Means/DBSCAN), dado que o comportamento dos metadados maliciosos quebra
significativamente o padrão de densidade e escala estabelecido pelos arquivos benignos.
